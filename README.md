# Task 3: Password Generator

This project was completed as part of my **Python Programming Internship at CodSoft**.

## Project Overview

This is a command-line Password Generator built using Python. It generates a password based on the user-selected length and character types.

## Features

- User-defined password length
- Option to include uppercase letters
- Option to include lowercase letters
- Option to include numbers
- Option to include special characters
- Basic password strength indicator
- Input validation and error handling
- Option to generate another password without restarting the program

## Technologies Used

- Python
- `random` module
- `string` module
- Functions
- Loops and conditional statements
- Exception handling

## How to Run

```bash
python task3_password_generator.py
```
